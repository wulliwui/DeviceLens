# 端鉴（DeviceLens）

[English README](README.md)

端鉴是一款 iOS 本机诊断工具，用于查看自己的 iPhone 或 iPad 的设备信息和运行环境迹象。由用户手动触发，无需服务器或第三方依赖。

## 功能

- **开始采集**读取设备、屏幕、系统、网络、应用和权限等信息。报告说明字段不可用的原因，并提供可与图灵盾和同盾配置格式对照的数字字段。
- **判断**显示越狱、Frida、调试器、动态库注入以及模拟器或 Mac 运行迹象。单独开放的回环端口只记为可疑。
- **导出报告文件**生成一份独立的 HTML，内含字段解释、当前构建使用的采集代码和原始 JSON。电脑可以离线打开，也可以从 iOS 通过隔空投送分享或保存到「文件」。

## 编译运行

1. 在 Xcode 打开 [DeviceLens.xcodeproj](DeviceLens.xcodeproj)，选择 **DeviceLens** scheme。最低支持 iOS 16.0。
2. 选择 iOS 模拟器，按 **⌘R** 运行。真机运行时，在 **Signing & Capabilities** 选择自己的开发团队，并使用团队可用的 Bundle ID。
3. 点 **开始采集** 或 **判断**。采集完成后点 **导出报告文件** 生成并分享文件。

SSID 和 BSSID 取值取决于签名能力和 iOS 条件。定位需要用户授权。较新的 iOS 上，CoreTelephony 可能返回占位值。

## 数据处理

仓库保存源代码和测试。报告在手机本机生成，实际文件可能包含机主的设备标识符、网络信息和授权后的坐标。端鉴不会自动发送诊断报告。分享由用户在 iOS 分享面板发起。

数字字段用于本机诊断和对照。第三方 SDK 及其在线服务不在本项目的实现范围内。
